**Path K — self-test safety: pre-run classification, exit codes, no-file transparency (macOS, host 2026-10-25): PASS.**
- The self-test now classifies the pre-run config **before anything may write**: `valid` (loads through `Config::load`, which itself enforces owner-only 0600), `missing` (first-class state), or `invalid/unsafe` (malformed content, or a file the app would never write — symlink, foreign uid, mode other than 0600). An invalid/unsafe pre-run file never gains a write: the config-mutating sections are not started, the file is left byte- and mode-exact, and the run exits **2** (skipped).
